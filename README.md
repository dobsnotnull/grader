# JS Grade Report Generator

A simple JavaScript project that generates a student's grade report based on their score.

## Features

* Calculates letter grades
* Determines pass or fail status
* Generates feedback based on the grade
* Includes both JavaScript and TypeScript versions

## Example

```js
createGradeReport("Doubra", 98);
```

Returns:

```js
{
  name: "Doubra",
  score: 98,
  grade: "A",
  passed: true,
  feedback: "Greatness"
}
```
